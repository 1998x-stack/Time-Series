# 设计: Hamilton《时间序列分析》全章节教程代码与文档增强

日期: 2026-08-17

## 1. 背景与目标

本项目是关于 Hamilton《Time Series Analysis》(中译本) 的中文学习教程。当前仓库包含:

- 22 个章节目录 (`第1章_差分方程` ~ `第22章_机制变化的时间序列建模`)
- 144 个小节,每个小节有一对同名文件: `.md`(理论教程文档,含 LaTeX 公式) 与 `.py` (代码实现)
- 除标准命名的各节外,第 1 章还有一个非标文件对 `Durbin-Levinson算法.md/.py`(内容已存在),但它**既不在 README 索引中,也不在 main.py 的 structure 中**——是一个待修补的缺口
- 绝大多数 (约 90%+) 的内容文件只是空模板(仅含头部),只有第 1-3 章的命名节(及白噪声/Durbin 等零散文件)有实质内容
- `README.md` 是手写的静态索引; `main.py` 保存一个章节 `structure` 字典

**目标**: 补齐全部 144 个小节的教程文档与可运行代码,使其达到并超越既有第 1–3 章的质量,并打磨项目级文档,形成一个可导航、可验证、教学完整的教程。

## 3. 架构与文件约定

目录结构不变,保留既有命名,只填充内容,不改名、不重排:

```
Time-Series/
├── README.md
├── main.py
├── introduction-time-series.pdf   (参考原著, 不改动)
└── 第N章_<name>/
    ├── NN_s.NM_<section>.md
    └── NN_s.NM_<section>.py
```

- **文件对不变量**: 每小节恰好一个同名 `.md` + 一个 `.py`; 所有既有文件名保持不变。
- **语言**: 文档与注释用中文; 代码标识符/API 用英文。
- **Python**: 3.10+; 标准科学栈 `numpy`, `scipy`, `matplotlib`; 不用 `statsmodels`、不用 pandas(除非某节确有需要)。
- **运行**: 每个 `.py` 可用 `python <file>.py` 独立运行, 秒级完成; 用固定 `np.random.default_rng(seed)` 保证可复现。

## 4. 小节 `.md` 模板

每个 `.md` 的结构固定,使 22 章阅读风格一致:

1. **头部(保留既有)**: `# NN_s.NM <标题>`; `"""Lecture: ... / Content: ..."""` 块; 再 `### 第N章 ...` + `#### s.NM <标题>`。
2. **引言**: 2–4 句,说明该概念及其在章节/全书中的位置。
3. **核心概念与定义**: 用 LaTeX (`$$...$$` 块式, `$...$` 行内) 给出模型与量,记号与 Hamilton 一致。
4. **关键结果与推导**: 核心公式、命题与推导; 关键结果给出推导步骤(如既有白噪声频谱推导), 不为求简而断言。
5. **计算方法**: 说明 `.py` 如何实现——算法步骤及其理由(理论→代码映射)。
6. **数值演示**: 配对 `.py` 模拟了什么、还原了哪些参数、应看到什么输出/图;
7. **小结**: 关键要点。

保真度/准确度规则: 记号遵循 Hamilton; 不虚构引用或伪定理; 标准结果表述正确; 长推导给出关键步骤。篇幅与每节难度匹配(参照第 3 章白噪声的深度)。

## 5. 小节 `.py` 代码模板

每个 `.py` 自包含且结构一致:

1. **头部(保留既有)**: `# NN_s.NM <标题>` + 注释块 `Lecture:... / Content:...`。
2. **导入**: 仅 `numpy`, `scipy`, `matplotlib`; matplotlib 用 `Agg`(或无头守卫 `plt.show()`)避免挂起。
3. **实现**: 自研算法, 清晰的函数/类; 英文标识符, 中文 docstring(Args/Returns), NumPy 类型。
4. **演示/验证**: 在 `if __name__ == "__main__":` 下, 固定种子模拟:
   - 从已知 DGP 生成数据,
   - 运行实现的估计/滤波/检验,
   - 打印恢复真值 vs 真值(有意义的画图存至本地 `plots/` 或显示)。
5. **运行并验证**: 构建时实际运行; 打印合理数字(估计接近模拟真值)且干净退出后才提交。

格式: PEP-8; 用 `np.newaxis`/广播做向量运算; 无法用闭式/网格时用 `scipy.optimize` 做 MLE/GMM; 谱相关工作用 `scipy.fft`/`scipy.signal`; 矩阵分解用 `scipy.linalg`; 固定种子保证可复现。

## 6. 验证工作流(每节)

每个小节提交前经过固定闸门:

1. 编写 `.md` 与 `.py`。
2. 干净 shell 运行 `python <file>.py`; 确认退出码 0、打印的恢复估计与真值在容差内一致、可选绘图无崩溃。
3. 对照已知 DGP 真值做常识核验(如 OLS 系数≈真值±标准误; MLE 回估真值等)。
4. 全部通过才提交; 若某节复用了更早小节的 DGP, 沿用同一种子约定以保证可复现。
5. 可选 `run_all_sections.py` 做批量冒烟, 但每个文件仍可独立运行。

目标: 完成时 **144 个 `.py`(含 `Durbin-算法`)全部可运行且通过验证**, 而非仅能编译。
